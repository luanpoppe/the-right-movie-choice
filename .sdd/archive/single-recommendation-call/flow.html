Schema F1.C1 · MovieRecommendationSchema

O envelope da invoke passa a ter cards e texto no mesmo Zod, alinhado ao JSON HTTP.

Como funciona

movies 0–3 itens; response string nonempty. A porta ainda tem dois métodos.

export const MovieRecommendationSchema = z.object({
  movies: z.array(SingleMovieReccomendationSchema).min(0).max(3),
  response: z.string().nonempty(),
});

Dados fluindo

{ movies: [], response: "..." } → parse ok 4 filmes → fail response "" → fail

Conecta

  • Fixture do spec do provider ganhou response.
  • Próximo: prompt único, ainda sem fundir invokes.

Prompt F1.C2 · MovieRecommendationPrompts

Um system prompt cobre cards (até 3) e o tom do response no mesmo JSON. As duas invokes do provider só passaram a usar esse texto.

Como funciona

unified() substitui structured() e chat(). Zero filmes + texto nonempty está explícito. Sem markdown e sem “outra IA escolheu”.

static unified() {
  return `...indicar até 03 filmes...
Se o pedido não puder ser atendido, devolva zero filmes.
No mesmo JSON, preencha o campo response...
não responda em markdown.`;
}

Dados fluindo

systemPrompt único → getMovieRecommendation (structured) → getChatResponse (ai.call) ainda duas calls até o chunk da porta

Conecta

  • AiMovieRecommendationProvider chama unified() nas duas linhas de prompt.
  • Próximo: um método na porta e uma callStructuredOutput.

Provider F1.C3 · AiMovieRecommendationProvider

Uma invoke structured devolve a entidade inteira. A porta tem um método. Sem ai.call.

Como funciona

getMovieRecommendation chama callStructuredOutput, faz safeParse e relança erro (incluindo threadId). O use case já mapeia { movies, response } para o HTTP não quebrar.

const result = await this.ai.callStructuredOutput({
  aiModel: AiModels.PRIMARY,
  systemPrompt,
  messages,
  threadId: chatId,
  outputSchema: MovieRecommendationSchema as never,
});
const parseResult = MovieRecommendationSchema.safeParse(result.response);
if (!parseResult.success) {
  throw new WrongMovieSchemaFromLlmException();
}

Dados fluindo

userMessage + chatId → uma callStructuredOutput → { movies, response } → use case espelha o JSON HTTP

Conecta

  • Porta IMovieRecommendationProvider.getMovieRecommendation.
  • Use case já consome isso (escopo extra deste chunk para a suíte ficar verde).

UseCase F1.C4 · GetMovieRecommendationUseCase

O execute faz uma chamada à porta e devolve o mesmo shape HTTP. Código já tinha chegado no chunk da porta.

Como funciona

Sem segunda call, sem histórico. Tester acrescentou casos de borda na suíte da feature.

const recommendation =
  await this.movieRecommendationProvider.getMovieRecommendation(
    userMessage,
    chatId,
  );
return {
  movies: recommendation.movies,
  response: recommendation.response,
};

Dados fluindo

userMessage + chatId → getMovieRecommendation → { movies, response }

Conecta

  • Controller HTTP inalterado.
  • Porta unificada no chunk do provider.
