Spec: unify-recommendation-call

Atualizado em 2026-09-04

Resumo

Uma invoke callStructuredOutput devolve cards e texto conversacional. Porta e use case passam a um método; o POST continua { movies, response }.

Requirements (cenários BDD)

REQ-1: Uma invoke, dois resultados

  • Dado que o usuário envia userMessage com chatId
  • Quando o use case roda
  • Então uma callStructuredOutput com threadId; sem ai.call; retorno { movies, response }

REQ-2: Schema Zod unificado

  • Então movies min 0 max 3 + response nonempty; falha → WrongMovieSchemaFromLlmException

REQ-3: Porta com um método

  • Então só getMovieRecommendation; somem os dois métodos atuais

REQ-4: Prompt único

  • Então uma função de prompt (cards + tom de chat, sem markdown)

Edge cases
  • Zero filmes + texto nonempty → 200 com array vazio
  • Mais de 3 filmes ou response vazia → exceção de schema
  • Erro de threadId não é engolido; factory/HTTP intactos

Contratos

Entidade em movie-recommendation.entity.ts. Porta getMovieRecommendation. DTO HTTP já alinhado — não mudar.
