Spec: agent-tmdb-tool-call

Atualizado em 2026-09-05

Resumo

O POST de recommendation passa uma tool Zod ao @luanpoppe/ai: o modelo pensa em mais candidatos do que vai devolver, faz uma chamada com até 8 { query, year? }, o adapter dispara Promise.all em MovieCatalogLookupService.findDetailsByTitle. O JSON interno pode trazer tmdbId/imdbId opcionais; o HTTP público continua sem esses campos. GET /movie/queries não recebe a tool.

Requirements (cenários BDD)

REQ-1: Uma chamada batch, lookups em paralelo

  • Dado que o provider registra a tool no callStructuredOutput
  • Quando o modelo invoca com { queries: [{ query, year? }, ...] } (1–8 itens)
  • Então Promise.all de lookup e array de resultados na mesma ordem

REQ-2: Schema interno com ids

  • Dado que o schema de recommendation inclui tmdbId/imdbId opcionais
  • Quando o modelo escolhe até 3 filmes depois da tool
  • Então copia ids do retorno; sem hit o parse não falha

REQ-3: HTTP público não vaza ids

  • Dado que o use case devolve a entidade interna
  • Quando o controller monta o body
  • Então mapeia para o schema público; destructuring sozinho vazaria campos extras

REQ-4: Prompt ensina batch e escolha

  • Dado que o system prompt unificado é o que o modelo lê
  • Quando há pedido de recomendação
  • Então pede pensar a mais, uma chamada com todas as queries, depois 0–3 filmes copiando ids

Edge cases
  • queries vazio ou > 8: Zod rejeita (min 1, max 8).
  • Query vazia num item: miss de F1 naquele índice.
  • Tool não chamada: ids ausentes; HTTP igual ao de hoje.
  • found: false: filme pode ir sem ids.
  • Falha de um lookup não cancela os outros.
  • GET /movie/queries sem esta tool.
  • DTO HTTP não reutiliza o Zod interno estendido.

Contratos

Input Zod da tool: { queries: { query: string; year?: number }[] } (1–8). Execute devolve MovieCatalogLookupResult[]. lookup unitário não muda. Entidade interna em movie-recommendation.entity.ts (tmdbId?, imdbId?). Público em movie-recommendation.dto.ts. Factory de recommendation (não a de exemplos). Prompt em movie-recommendation-prompts.ts.
