Spec: tmdb-http-client

Atualizado em 2026-09-01

Resumo

Transporte HTTP v3 da TMDB. Porta de catálogo: searchMovies e getMovieDetails. Cache, DTOs e rotas debug na feature seguinte.

Requirements (cenários BDD)

REQ-1: GET 200 com Bearer e language

  • Dado que o client tem token e um fetch injetado que responde 200 JSON
  • Quando getMovieDetails(11)
  • Então a URL inclui language=pt-BR, Bearer, e o JSON parseado é retornado

REQ-2: Retry em 429 e depois sucesso

  • Dado que o fetch devolve 429, 429 e 200
  • Quando searchMovies ou getMovieDetails é chamado
  • Então 3 tentativas, backoff 1000ms × 2^n, retorno do 200

REQ-3: 401 da TMDB vira TmdbHttpException

  • Dado que o fetch devolve 401
  • Quando searchMovies ou getMovieDetails é chamado
  • Então TmdbHttpException com statusCode 502; sem retry

REQ-4: Timeout da tentativa

  • Dado que o fetch não resolve em 5s
  • Quando searchMovies ou getMovieDetails é chamado
  • Então aborta; se esgotar tentativas, TmdbHttpException 504

Edge cases
  • Token ausente em test → erro de config antes do fetch.
  • 404 → 404, sem retry; 5xx persistente → 503; 400/JSON inválido → 502.
  • Query do caller pode sobrescrever language.
  • Log sem Bearer.

Contratos

 
IMovieCatalogProvider.searchMovies / getMovieDetails
timeout 5000ms · 2 retries · backoff base 1000ms
TMDB_ACCESS_TOKEN obrigatório fora de test
