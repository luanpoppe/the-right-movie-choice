Spec: tmdb-movie-queries

Atualizado em 2026-09-02

Resumo

Catálogo tipado (Zod + mapper), cache Redis só de details 24h, GETs debug em dev/test só a partir desta máquina (loopback). Sem chat e sem cache de search.

Requirements (cenários BDD)

REQ-1: Search devolve hits, não ficha

  • Dado que a TMDB responde 200 em /search/movie
  • Quando searchMovies ou GET /debug/tmdb/search
  • Então { page, results: MovieSearchHit[] }; page default 1; sem include_adult

REQ-2: Details mapeado + cache miss

  • Dado que Redis não tem catalog:movie:{id}:{lang}
  • Quando details
  • Então TMDB → Zod → MovieCatalogDetails → Redis TTL 24h (sem renovar no hit)

REQ-3: Details cache hit

  • Dado que a chave existe
  • Quando details de novo
  • Então sem TMDB; DTO cacheado; TTL não resetado

REQ-4: Debug só nesta máquina (loopback)

  • Dado que dev/test e o cliente é loopback (127.0.0.1 / ::1 / localhost — não LAN nem IP público)
  • Quando os GETs /debug/tmdb/…
  • Então DTO; rotas inexistentes em prod; outro IP recusado (não é JWT). Postman em localhost passa; internet não usa o backend como proxy da TMDB.

Edge cases
  • Zod TMDB falha → TmdbHttpException 502 Bad Gateway (nós somos o gateway; a TMDB mandou corpo inútil). Não é 400 nem 500. Igual JSON inválido / 401 no client HTTP.
  • Redis fora → log, TMDB, sem gravar cache.
  • 404 details; search vazia []; query vazia no debug → 400.
  • Live só script com token; pnpm test sem live.

Contratos

 
searchMovies → { page, results: MovieSearchHit[] }
getMovieDetails → MovieCatalogDetails
GET /debug/tmdb/search?query=&page=
GET /debug/tmdb/movies/:id
Redis catalog:movie:{id}:{lang} · DTO · 24h · sem refresh
