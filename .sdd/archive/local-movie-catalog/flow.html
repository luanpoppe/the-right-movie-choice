Schema F1.C1 · Movie

Tabela Movie e cinco filhas no Prisma, com unique por idioma. É a base física do catálogo local.

Como funciona

Uma linha de filme por par tmdbId+language. Listas viram tabelas com cascade. País de origem ficou no campo code.

model Movie {
  id              Int      @id @default(autoincrement())
  tmdbId          Int
  language        String
  title           String
  imdbId          String?
  genres          MovieGenre[]
  @@unique([tmdbId, language])
  @@unique([imdbId, language])
}

static toDetails(movieWithChildren: MovieWithChildren): MovieCatalogDetails {

    watchProviders,
    imdbId: movieWithChildren.imdbId,

Freshness F2.C2 · MovieCatalogFreshnessUtils

Decide se a linha do Postgres ainda vale: idade estritamente menor que 30 dias.

Como funciona

Compara now.getTime() - updatedAt.getTime() com FRESH_FOR_MS. Igual a 30 dias já é velho.

const ageMs = nowMs - updatedAtMs;
if (ageMs >= freshForMs) {
  return false;
}
return true;

Como funciona

Banco fresco aquece Redis. Banco velho tenta TMDB; se TMDB falhar, devolve a ficha velha. Prisma throw pula para TMDB. Miss local + TMDB ok grava só Redis.

const cachedDetails = await this.cache.get(tmdbId, lang);
if (hasCachedDetails) {
  return cachedDetails;
}
const localRecord = await MovieCatalogDetailsResolver.findLocalRecordSafely(...);
if (hasLocalRecord) {
  return this.resolveFromLocalRecord(...);
}
return this.fetchFromTmdbAndCache(tmdbId, lang);

Processor F3.C2 · CatalogPersistProcessor

Valida o payload, chama upsert no repositório local e não fala com o TMDB. Conflito de IMDb e payload inválido completam o job.

Como funciona

Payload inválido ou MovieCatalogImdbConflictException viram return após log. Erro transitório (ex.: Postgres fora) é logado e relançado para o Worker retryar.

await this.repository.upsert(details, language);
…
if (isImdbConflict) {
  Logger.warn("Movie catalog IMDb conflict during persist", { imdbId, language });
  return;
}
Logger.error("Catalog persist job failed", { durationMs, success: false, tmdbId, reason });
throw error;

Dados fluindo

  • Usa IMovieCatalogRepository.upsert e o tipo do contrato da fila.
  • O Worker BullMQ (próximo chunk) só precisa chamar process.

Resolver F4.C2 · enqueue após TMDB
