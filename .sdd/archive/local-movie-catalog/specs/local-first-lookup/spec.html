Spec: local-first-lookup

Atualizado em 2026-09-05

Resumo

Lookup do agente e GET de details em /debug/tmdb leem Redis → Postgres → TMDB. Título tenta o banco antes do search TMDB. Ficha com updatedAt há menos de 30 dias vence. Sem upsert no Postgres nesta feature; miss TMDB ainda grava Redis (24h). Search debug continua só TMDB.

Requirements

REQ-1: Agente acha filme já catalogado pelo título

  • Dado que query Interestelar e linha pt-BR com updatedAt há 3 dias
  • Quando findDetailsByTitle roda
  • Então não chama search TMDB; found: true; aquece Redis (157336, pt-BR)

REQ-2: Agente não acha no banco e cai no TMDB

  • Dado que nenhum título contém Duna em pt-BR
  • Quando o agente busca Duna
  • Então search TMDB + 1º hit + details Redis → banco fresco → TMDB; se veio do TMDB, grava só Redis

REQ-3: Debug GET details no mesmo pipeline

  • Dado que GET /debug/tmdb/movies/157336
  • Quando o controller resolve
  • Então mesmo pipeline; HTTP 200; miss TMDB grava Redis, não Postgres. Id inválido: 400

REQ-4: Banco velho (> 30 dias) busca TMDB

  • Entrada 157336 pt-BR, updatedAt há 31 dias, Redis vazio
  • Saída details TMDB na resposta (ou ficha velha se TMDB falhar + log); Redis se TMDB ok. Sem upsert e sem fila nesta feature — atualizar o Postgres velho é catalog-persist-worker + enqueue-on-tmdb-miss.
  • Erro TMDB fora e sem linha: miss amigável no agente

REQ-5: Camada fora do ar é pulada

  • Entrada Redis ou find Prisma lança
  • Saída loga e segue (Redis → banco → TMDB / search)
  • Erro TMDB HTTP sem fallback: miss de catálogo indisponível

REQ-6: Search debug não usa o catálogo local

  • Dado que search debug query=star
  • Quando a busca roda
  • Então só TMDB searchMovies; 200; sem Postgres

Edge cases
  • Hit Redis (24h) ignora frescor de 30 dias do banco até o TTL acabar.
  • Empate de título: findByTitleAndYear (unaccent, updatedAt DESC).
  • Idioma omitido: pt-BR. Idioma informado (ex. en-US) vale no find local, na chave Redis e na TMDB; watch_region continua BR.
  • Query vazia no agente: miss atual, sem TMDB.

Contratos expostos

Lookup: movie-catalog-lookup.service.ts (findDetailsByTitle). Cache: TmdbMovieDetailsCache. Debug: tmdb-debug.controller.ts. Porta: IMovieCatalogProvider. Reads: IMovieCatalogRepository.
