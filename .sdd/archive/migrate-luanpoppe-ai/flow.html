Env F1.C1 · env.ts

Contrato de boot: OpenRouter obrigatório em dev/prod; Gemini vazio é válido e o LangChain legado ainda recebe string.

Como funciona

Fora de test, o superRefine marca TMDB e OpenRouter em issues independentes. Gemini usa default "".

GEMINI_API_KEY: z.string().optional().default(""),
OPENROUTER_API_KEY: z.string().optional(),

Dados fluindo

NODE_ENV=dev sem OPENROUTER_API_KEY → parse falha GEMINI ausente → env.GEMINI_API_KEY === ""

Conecta

  • O adapter futuro lê essas chaves ao montar new AI().

Constantes F1.C2 · AiModels

Pacote @luanpoppe/ai e slugs. Sem wrapper: o próximo adapter faz new AI().

Como funciona

PRIMARY é DeepSeek via OpenRouter; GEMINI_FALLBACK só entra no construtor se a chave Gemini não for vazia (isso fica no provider).

export class AiModels {
  static readonly PRIMARY = "openrouter/deepseek/deepseek-v4-flash" as const;
  static readonly GEMINI_FALLBACK = "gemini-2.5-flash" as const;
}

Dados fluindo

factory do provider → new AI({ openRouterApiKey, googleGeminiToken? }) → ai.call / ai.callStructuredOutput({ aiModel: AiModels.PRIMARY })

Conecta

  • A factory de recommendation instancia AI no POST.

  ...(hasOpenRouterApiKey ? { openRouterApiKey } : {}),
  ...(hasGeminiApiKey
